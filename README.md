# Para clonar el repositorio, usar el siguiente comando: git clone --recurse-submodules.

# Para levantar el proyecto se debe entrar a la carpeta "TP-CasaInteligente" y levantar el archivo .sln con Visual Studio (yo uso Community 2022).

# En la carpeta frontend-casainteligente se encuentra la interfaz grafica hecha en React y montada con el paquete Electron.

# Para levantar el frontend en el directorio .../frontend-casainteligente hacer npm install y npm run dev.
 
# Para actualizar el frontend con la ultima version de la simulacion, se debe compilar el proyecto y pegar el ejecutable CasaInteligente.exe en la carpeta. Usar siempre WIN32 y Debug. El ejecutable se suele guardar en WIN32/Debug. Esto se debe hacer cada vez que queramos actualizar el codigo de la simulacion y que se vea reflejado en el frontend.

# Para iniciar la interfaz grafica, se debe ejecutar el programa "Casa Inteligente.exe".

# Para generar el ejecutable final de la interfaz grafica, se debe ejecutar CasaInteligente.bat.
